# Comment puis-je simplement afficher le panneau d'aperçu sans le panneau d'édition des notes ?

Ouvrez **Préférences > Interface > Dispositions**, sélectionnez la disposition, puis choisissez **Aperçu de la note** comme **widget central**.

Vous pouvez d’abord créer une nouvelle disposition avec **Ajouter depuis la disposition courante**, ou utilisez **Ajouter depuis un préréglage…** et sélectionnez le préréglage **Prévisualisation uniquement**.

Ensuite, désactivez le panneau d’édition de note dans le menu **Fenêtre > Panneaux**. La prévisualisation utilisera automatiquement la zone centrale libre.

Gardez à l'esprit que vous pouvez déplacer tous les panneaux à votre guise en cliquant sur **Fenêtre / Déverrouiller les panneaux** dans le menu principal. Vous pouvez également redimensionner tous les panneaux en fonction de vos besoins.
