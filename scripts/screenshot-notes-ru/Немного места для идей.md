# Немного места для идей

Ваши заметки. Ваши файлы. Ваше пространство.

QOwnNotes хранит повседневные мысли в виде простого текста в Markdown,
чтобы их было легко исследовать, связывать и делать своими.

## Место для главного

- **Записывайте** идею, пока она не ускользнула
- **Связывайте** свои исследования ссылками между заметками
- **Создавайте** то, к чему захочется вернуться

## Маленькие приключения этой недели

- [x] Найти тихое место для письма
- [x] Собрать вдохновение для следующего проекта
- [ ] Превратить хорошую идею в первый черновик
- [ ] Оставить немного места для неожиданного
